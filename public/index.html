🍪 导入 Cookie

方法 A（最简单，10 秒）：在已登录的 studentbeans 页面按 F12 → Console/控制台 → 输入 document.cookie → 回车 → 复制输出的一整串

方法 B（A 输出为空时用）：F12 → Network/网络 → F5 刷新 → 右键点任意 studentbeans.com 请求 → Copy → Copy as cURL (bash) → 整段粘贴到下面

方法 C：Network → 点请求 → Headers/标头 → 展开 Request Headers/请求标头 → 复制 cookie: 后整串
